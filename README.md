# CrudApp

This project was generated with [Angular CLI](https://github.com/angular/angular-cli) version 18.2.2.

This is simple CRUD operation with filtering.

## Development server

Run `ng serve` for a dev server. Navigate to `http://localhost:4200/`. The application will automatically reload if you change any of the source files.

## How to start project

1. install node_model `npm install`
2. start json server `npx json-server --watch db.json --port 8080` Ps. you can choose different port
3. finally start porject `npm start`
